# Redakční styl

Jediným kanonickým zdrojem závazných pravidel je
`REDAKCNI_MANUAL.md`. Ostatní soubory jej rozvíjejí a při případném rozporu
mu jsou podřízené.

## Dokumenty

- `REDAKCNI_MANUAL.md` – etika, styl, ověřování, žánry a publikační provoz.
- `STYL_DATOVA_ZURNALISTIKA.md` – datová žurnalistika s příklady.
- `NAVOD_STYL_TRESNAK.md` – vyprávěcí nástroje a civilní čeština.
- `REUTERS_INSPIRACE.md` – rozbor vybraných formátů Reuters Graphics.

Projektové dodatky jsou v `docs/specialy/<název>/`.

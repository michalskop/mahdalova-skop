# Instructions for Gemini and other AI tools

This repository uses one set of rules for every AI tool. Read and follow both files before any work:

- `AGENTS.md` – hard rules for writing articles, URLs, covers and publishing.
- `CLAUDE.md` – architecture, article pipeline and the same hard rules in more detail.

Before writing or editing any article text, read `docs/redakcni-styl/REDAKCNI_MANUAL.md` in full. It is the binding editorial manual. `npm run check:articles --workspace=apps/web` must pass before an article can be committed or deployed.

# Referenční prototypy

`kviff-film-origins-dashboard.html` je samostatný návrhový prototyp
vizualizace původu filmů z července 2026. Není nasazován na web.

Prototyp lze znovu vytvořit skriptem
`apps/web/app/specialy/kviff/_pipeline/film-origins/build-kviff-origin-dashboard.mjs`.
Při regeneraci vzniká také varianta `kviff-film-origins-dashboard-inline.html`.

Poster editor

Click an object in the preview → edit it on the right. Drag to move; corners/sides resize. Double-click a text to edit it on the canvas.
Content
První slovo je standardně červené, zbytek světlý na tmavém pozadí. Část textu lze přebarvit označením na ploše.
Enter = nový řádek, i po změně šířky textového rámu.
Format
Chapter / accent colour
15 chapters = 15 colours from DPBP_CHAPTERS. Picking a chapter changes only the accent colour; the texts stay as you typed them.
Image / motif
Vlož původní fotografii nebo ilustraci bez titulku a loga. Texty a značky doplní editor; export obsahuje celou kompozici. Zdrojový obrázek a uložený projekt si ponech pro další úpravy.
Or drop a file here / paste (Ctrl+V). After inserting, click the image in the preview → zoom, pan, stretch, border.
No image → a pictogram is used:
Projekt a export
OG image – the preview used when the article link is shared (FB, WhatsApp, X, LinkedIn…). The site declares it in og:image and the network fetches it itself. Auto picks JPEG (photo/gradient) or PNG (graphics, text, solid areas). Default 1200×630 px.
SVG (web) is only for embedding the preview directly in a web page, not for social networks.

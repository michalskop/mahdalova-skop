# Data o klimatu

Tematická stránka pro analýzy a datovou žurnalistiku o změnách klimatu,
jejich dopadech a klimatické politice.

- Produkční URL: `/specialy/klima`
- Kód: `apps/web/app/specialy/klima/`
- Hlavní implementace: `apps/web/app/specialy/klima/page.tsx`

Speciál je v současnosti jednoduchá tematická landing page. Budoucí informace
o datových zdrojích, metodice, výběru článků, designu a QA patří sem.

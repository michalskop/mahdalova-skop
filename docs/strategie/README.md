# Strategie

Strategické podklady pro provoz DataTimes / Mahdalová & Škop, které se
nenasazují jako součást webu, ale řídí rozhodnutí v `apps/`.

## Dokumenty

- [`PODPOROVATELE.md`](PODPOROVATELE.md) — jak oslovujeme, získáváme a udržíme
  platící podporovatele; podklad pro stránku `/klub` a komunikaci na sítích.
  Rozpracovává pilíř „komunita a crowdfunding" z finančního modelu v
  `impact-materials`.

## Vztah k ostatní dokumentaci

- Etické mantinely (přiznání financování, redakční nezávislost, konflikt
  zájmů) jsou závazně v [`../redakcni-styl/REDAKCNI_MANUAL.md`](../redakcni-styl/REDAKCNI_MANUAL.md).
- Vizuální systém stránek je v [`../design/DESIGN.md`](../design/DESIGN.md).
- Celkový finanční model („šest zdrojů, tři fáze") žije v samostatném repu
  `impact-materials` (`projects/datatimes/`).

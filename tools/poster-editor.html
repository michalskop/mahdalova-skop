Using the output
SVG — thumbnails on the web. Embed it inline (<svg> directly in the HTML) so it picks up Roboto Slab / Condensed that the site already loads. As <img src="…svg"> the fonts fall back to Georgia/Arial.
PNG — og:image for social networks (they don't take SVG). Fonts are baked in, so it needs an internet connection.

Using the output
SVG – thumbnails on the web. Embed it inline (<svg> directly in the HTML) so it picks up IBM Plex Serif / Sans that the site already loads.
PNG – og:image for social networks (they don't take SVG). Fonts are baked in, so it needs an internet connection.

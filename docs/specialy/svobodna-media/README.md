# Svobodná média

Tematická stránka sdružující texty o svobodě médií, jejich vlastnictví a
nezávislosti.

- Produkční URL: `/specialy/svobodna-media`
- Kód: `apps/web/app/specialy/svobodna-media/`
- Hlavní implementace: `apps/web/app/specialy/svobodna-media/page.tsx`

Speciál je v současnosti jednoduchá tematická landing page. Budoucí informace
o výběru obsahu, redakčních kritériích, designu a QA patří do této složky.

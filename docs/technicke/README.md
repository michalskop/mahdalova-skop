# Technická dokumentace

Průřezové implementační a provozní podklady, které nepatří k jedinému
speciálu.

- `ai-readability/` – AI čitelnost, agent-ready prvky, testování a historie
  implementace.
- `search/` – implementace fulltextového vyhledávání.

Dokončené implementační plány zůstávají jako historický a provozní záznam,
ne jako aktivní úkolovník.
